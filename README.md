# 🟢🔴🔵🟡 SIMON GAME    

## **OVERVIEW**    
This is a classic **Simon Game** built using **HTML, CSS, and JavaScript**. The game tests your memory by making you repeat an increasingly long sequence of colors and sounds. How far can you go?

## **FEATURES**    
✅ **Classic Simon Game Logic** – Follow the color pattern and repeat it        
✅ **Dynamic Gameplay** – Sequence gets harder as you progress        
✅ **Sound Effects** – Each color has a unique sound        
✅ **Responsive Design** – Playable on desktop and mobile devices        
✅ **Highscore Tracking** – Optional feature to track the longest sequence

## **HOW TO PLAY**
1️⃣ Press any key to start the game.  
2️⃣ Watch the color sequence displayed by the game.  
3️⃣ Click the colors in the same order.  
4️⃣ If you repeat the sequence correctly, you move to the next level.  
5️⃣ If you make a mistake, the game ends – try again!
